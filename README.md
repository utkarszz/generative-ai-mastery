# Generative AI Mastery

A long-term, intuition-first learning repository for Generative AI and backend engineering. Preserve your original explanations; never infer understanding or completed work.

## Learning approach

For each topic: understand why it exists and the problem it solves; record your intuition in your own words; assess it; study the technical explanation, math, and internal working; implement it; connect it to backend engineering; complete exercises and mastery checks; document refined understanding.

## Technology architecture

- AI and model work: Python, NumPy, Pandas, PyTorch, Hugging Face, Transformers, training, and fine-tuning.
- Backend engineering: TypeScript, Node.js, Express.js, MongoDB, Redis, BullMQ, production APIs, and AI orchestration.

## Repository map

The current phase is `00-programming-prerequisites/`. Later phases are placeholders; lesson files will be added as topics are taught. See [ROADMAP.md](ROADMAP.md) and [PROGRESS.md](PROGRESS.md).

## Learning Review Template

Every completed lesson review must contain:

1. Topic Overview
2. My Initial Intuition
3. Intuition Assessment
4. Correct Technical Explanation
5. Mathematical Foundations
6. Internal Working
7. Implementation
8. Backend Engineering Connection
9. Mistakes and Doubt Resolution
10. My Refined Intuition
11. Exercises and Mastery Check
12. Key Takeaways
13. References

Use clear numbered headings, language-tagged code blocks, accurate math, useful diagrams and examples, and links to related lessons. Avoid duplicated explanations.
